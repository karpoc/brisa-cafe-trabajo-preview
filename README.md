# Brisa · Café y trabajo · preview

Sitio publicado: https://karpoc.github.io/brisa-cafe-trabajo-preview/

Este repositorio contiene solo el build estático de la demo. El código fuente vive en el repositorio privado `karpoc/brisa-cafe-trabajo`, compartido con Kodarvia.

La demo usa datos ficticios y guarda reservas, avisos simulados y ajustes de cupos en el navegador. No envía correos ni procesa pagos. El botón de WhatsApp abre `wa.me` con el resumen ya redactado, pero el mensaje lo envía la persona desde su cuenta.
